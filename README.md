# 卫戍协议·规程 · 盟约与阵容研究

**从盟约找到干员，从特质找到联动，把本局信息和阵容放在一起看。**

《明日方舟》**卫戍协议·规程**的非官方玩家工具，由 [WakingSeasons](https://github.com/WakingSeasons) 制作和维护。支持电脑与手机浏览器，无需登录。

[打开在线工具](https://wakingseasons.github.io/garrison-tool/) · [本次更新：v1.0.5](docs/releases/v1.0.5.md) · [完整更新记录](CHANGELOG.md) · [反馈问题](https://github.com/WakingSeasons/garrison-tool/issues)

## 能做什么

### 找干员，也找联动

- **特质分类筛选**：按阶级、核心盟约、独立盟约、特质分类和联动词条组合筛选，支持单选、多选全部满足或任一满足。叠层相关特质进一步区分获得叠层、定额叠层、条件叠层、叠层增幅等作用。
- **机制联动查询**：围绕「获得干员」「休整期结束时」等词条，查看有关的干员特质、战斗技能、角色策略和成立条件。
- **并排检索**：左边保留炎，右边继续找奥术。点击干员卡片上的盟约也能打开右侧检索；两侧各自保留条件，共用底部阵容。手机使用左右检索切换。
- **两种搜索**：顶部任意词检索资料内容；干员列表另有名称搜索。卡片支持普通／精锐切换，详情提供对应练度和 PRTS 基础档案入口。

### 围绕当前这局配队

- **本局 BAN 位**：录入不可用盟约，按工具现有规则标红干员，也可选择隐藏；两侧检索共用 BAN 设置。
- **阵容管理**：添加干员、切换普通／精锐、配置转职，查看人数和各盟约的人数／触发进度，点击盟约查看具体效果；支持清空当前阵容。
- **状态保留**：筛选、当前阵容、BAN 位和标记名单保存在当前浏览器。阵容人数默认显示 n/8，相关配置可调整显示上限，不做硬性拦截。

### 截图带入本局信息（试用）

- **上传、拖入或粘贴截图**，一张截全即可，信息缺失时可补第二张，每次最多两张。
- **文字展示识别结果**：包括模拟方式、难度、Boss、特训敌人和盟约点亮／置灰状态。信息缺失或冲突时提示核对，不能直接套用。
- **一键套用到本局**：完整结果核对后，更新共用 BAN 位和敌方资料的「本局」分类，保留阵容、两侧筛选及标记名单。
- **标记关注的干员或盟约**：输入名字后从候选添加，支持逐项删除。识别后显示「未被 BAN／被 BAN／待确认」，增删即时更新，无需重新识别。名单与阵容独立保存。
- **本地处理**：图片在当前浏览器内识别，不上传服务器，不需要付费识别接口。首次识别需加载本地站点提供的文字识别资源，耗时取决于网络和设备。

### 集中查资料

- **敌方资料**：10 名 Boss、九类特训敌人、179 种候选敌人，提供头像、名称和对应 PRTS 链接。支持名称／类别搜索，套用截图后可集中看本局相关敌人。
- **盟约报告**：查触发人数和盟约效果，也可从干员或阵容上的盟约入口查看。
- **策略报告**：按角色或策略名检索，提供角色名字、头像和策略效果。
- **装备一览**：按等阶查询装备和联合效果，说明转职占两个装备位置、同名装备合并等区别。
- **友情链接**：集中进入路标档案馆出怪预览、PRTS 与可露希尔 Wiki 的本季资料。

## 从哪里开始

1. **想找搭配**：进入「卫戍干员」→展开筛选→选盟约或特质→点卡片盟约并排查看→加入底部阵容。
2. **已经开局**：进入「截图识别」→参考可放大的截图示范→上传本局截图→核对文字与标记结果→点击「套用到本局」。
3. **只想查敌人**：进入「敌方资料」→选 Boss 或特训类别→点击头像／名称打开对应 PRTS 页面。

网页顶部的「特色介绍」和版本按钮可随时查看功能入口与更新记录。手机端点击右上角「⋯」展开机制联动、并排检索、介绍、作者及版本入口，默认把空间留给搜索和资料内容。

## 当前边界与常见问题

- **正式版范围**：v1.0.0 是工具主体的首个正式版；截图识别仍处于试用阶段，已用所提供的示例截图验证，尚不能保证各种分辨率、压缩程度和游戏界面都能准确识别。
- **BAN 判断**：当前仍沿用工具既有规则——非特殊单位的固定盟约全部不可用时标为被 BAN。该规则参考上一期，尚未完整核实本季全部细节。截图功能没有直接读取底部禁用干员头像名单，标记结果是由识别到的盟约状态推断的，实际名单以游戏为准。
- **识别不全**：保留左上角难度、完整盟约名称和右侧敌方信息；可以补一张同局截图，尽量与第一张保留重叠盟约。已传两张时，移除不完整的一张再补。不要混用不同局或不同次选择的截图。
- **首次识别较慢／加载失败**：等待识别资源加载，检查网络后重试；设备性能较弱时可用电脑浏览器。资料检索与手动 BAN 功能可单独使用。
- **敌人排序**：按本季出怪配置中的战力参考值排列，不代表绝对实战难度。分类展示候选池，实际出怪仍随回合、难度与随机结果变化。
- **本机保存**：不同设备、浏览器及网站域名之间不自动同步；清除网站数据会删除本机保存。多套阵容保存／预设和站位编辑仍待制作。
- **反馈错误**：请在 [Issues](https://github.com/WakingSeasons/garrison-tool/issues) 提供浏览器、设备、问题步骤；识别问题附原始截图和错误结果会更方便排查，注意遮去无关个人信息。
