# 卫戍协议·规程 · 盟约与阵容研究

[打开在线工具](https://wakingseasons.github.io/garrison-tool/)

《明日方舟》卫戍协议·规程的非官方玩家工具。当前为 v0.1 试用版，由 [@WakingSeasons](https://github.com/WakingSeasons) 发布和维护。

- 按等阶、盟约、特质和联动词条筛选干员，可并排查看两个检索区和盟约效果。
- 配队时查看盟约激活人数和下一档门槛，支持转职装备和手动标记本局 BAN 位。
- 查阅策略、装备和联合配方，区分占两个位置的转职配装与合并成一件的装备。

阵容和筛选保存在当前浏览器里。本局 BAN 位参考上一期规则，作为筛选辅助使用。

资料参考 [PRTS](https://prts.wiki/w/卫戍协议·规程)、[可露希尔 Wiki](https://closure.wiki/zh-cn/stronghold-protocol/3) 和 [NGA 数据讨论](https://nga.178.com/read.php?tid=47877197)。游戏名称、角色和头像等素材归相应权利方所有。
