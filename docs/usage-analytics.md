# 访问统计

正式站使用免费托管的 [GoatCounter](https://www.goatcounter.com/)。维护者登录[统计后台](https://garrison-tool.goatcounter.com/)查看访问和事件，网页上没有公开访客计数。统计从启用后开始。

| 统计项 | 何时记录 |
| --- | --- |
| 网页访问 | 打开正式站 |
| 套用本局信息 | 确认内容成功套用 |
| 加入阵容 | 成功添加一个干员 |
| 查看 Boss 波次 | 成功打开领袖波次属性 |

每次打开网页，同一项最多发送一次。请求只包含固定的页面或事件名称，不带搜索词、截图、识别结果或阵容信息。统计请求使用 GoatCounter 的[公开浏览器端点](https://www.goatcounter.com/help/pixel)，不加载第三方 JavaScript。统计可能受浏览器拦截和网络状况影响。

维护者可在正式站打开「特色介绍」，勾选「不统计此浏览器的后续访问」，避免把自己的日常调试计入。访客也可使用同一选项。开发预览和自动化浏览器不会上报。清空 `index.html` 中的 `data-goatcounter-site` 并重新发布即可停用统计。
