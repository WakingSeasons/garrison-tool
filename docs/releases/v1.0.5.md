# 卫戍协议·规程 v1.0.5：特训类别局部补读

修复完整截图中某一行特训类别被文字识别读成乱码，导致结果只有 2/3 类的问题。

- 首轮未读全时，仅对未识别行的类别名称做局部、放大的单行补读。
- 减少公共前缀和旁边鼠标指针等图案的干扰，补读结果按原图顺序展示。
- 仍只接受九种已知类别。没有读到的内容继续保留待确认，不根据“还差一项”猜测补齐。
