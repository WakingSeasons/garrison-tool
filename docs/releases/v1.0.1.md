# 卫戍协议·规程 v1.0.1：手机界面精简

根据手机端的使用反馈，这次把屏幕空间优先留给搜索、干员和阵容等核心内容。

- **顶栏改为一行「搜索＋⋯」**。机制联动、并排检索、特色介绍、作者和版本入口，点击右上角「⋯」展开。
- **减少重复信息**：隐藏栏目英文标题、介绍性文案、默认保存提示和空阵容说明，压缩栏目标题与导航高度。
- **核心信息保留**：筛选、盟约具体效果、触发人数与阵容进度继续显示和使用。
- **横屏同步精简**：展开菜单浮在正文上方，不挤占内容高度；点外部、选择功能或按 Escape 可收起。

电脑端保留现有布局。浏览器里保存的阵容、筛选、BAN 位和标记名单继续保留。
