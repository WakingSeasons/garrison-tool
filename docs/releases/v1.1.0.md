# 卫戍协议·规程 v1.1.0：暂停截图、修正补全与部分套用

本次将截图识别从“全部读全才能用”调整为“确认的内容先用，缺失的内容可以补”。

- **支持暂停截图**：没有模式、难度也可套用已知内容；模式未知不再按同盟三类报错。
- **修正／补全**：展开小入口，可修改模式、难度、Boss、特训类别和盟约状态，文字结果和关注提醒实时更新。
- **套用已识别内容**：分别更新确认的BAN、Boss和特训类别，保留阵容、两侧筛选与标记名单。
- **明确保留了什么**：缺失／冲突字段沿用原设置并标为待核对；未知盟约不作为确定BAN依据，也不会因此隐藏干员。
- **冲突需要确认**：两张图的信息冲突可逐项处理；特训类别需要明确确认当前勾选，其他已确认内容仍可使用。
- **刷新后仍可核对**：BAN与敌方“本局”的待核对标记保存于当前浏览器。

例如暂停图已识别26个盟约和两类特训，却没有模式和Boss：可以先套用这些内容，再展开补选“独立模拟”和对应Boss。不必为缺少开局信息重新截图。

截图识别仍为试用功能，BAN结论沿用工具既有规则，最终以游戏内名单为准。
