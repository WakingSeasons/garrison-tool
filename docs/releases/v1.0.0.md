# 卫戍协议·规程辅助工具 v1.0.0：敌方资料、截图识别与关注干员提醒

把之前做的卫戍协议·规程检索和配队工具整理成正式版了，电脑和手机浏览器都可以直接使用。

**使用地址：[打开卫戍协议·规程工具](https://wakingseasons.github.io/garrison-tool/)**

## 这个工具能做什么

想找叠层干员，可以按特质分类筛；想找机制配合，可以按联动词条查相关干员、战斗技能和策略。左边保留一个盟约，右边继续查另一个，点击干员头上的盟约也能并排打开。

底部阵容跨栏目共用，支持普通／精锐切换和转职配置，会显示人数、盟约触发进度与效果。本局 BAN 位可以手动录入，对应干员标红，也能选择隐藏。

另外可以查询盟约报告、带角色名字和头像的策略报告、装备与联合效果，以及本次加入的敌方资料。

## 这次更新了什么

- **敌方资料开放**：按 Boss 和九类特训敌人分类，查看名字、头像，点击就能打开对应 PRTS 页面。
- **截图识别试用**：上传本局信息界面的截图，以文字显示 Boss、特训敌人、难度和盟约状态。一张截全就够，缺失时可以补第二张，最多两张。
- **识别结果一键套用**：核对完整结果后，更新本局 BAN 位和敌方资料的「本局」筛选，原有阵容和左右检索继续保留。
- **关注干员／盟约提醒**：输入名字添加关心的对象，识别后集中查看哪些未被 BAN、哪些被 BAN、哪些还待确认；默认名单可以自由增删，并在本机保存。
- **友情链接**：集中放了路标档案馆出怪预览、PRTS 和可露希尔 Wiki 的相关入口。

本次相对线上 v0.4 更新；中间的 v0.5–v0.7 是开发记录，一并在 v1.0.0 上线。

## 使用前看一下

截图在浏览器本地处理，不上传服务器，也不需要付费识别接口；第一次识别需要等待资源加载。截图识别仍是试用功能，建议对照原图核对后再套用。

**BAN 提醒目前按盟约状态和工具现有规则推断，没有直接识别底部禁用干员头像名单，本季规则细节仍待核实，最终以游戏内名单为准。** 敌方列表展示候选池，实际出怪仍受回合、难度和随机结果影响。

阵容、筛选和标记名单保存在当前浏览器，不支持跨设备同步。阵容预设和站位功能还没做。
