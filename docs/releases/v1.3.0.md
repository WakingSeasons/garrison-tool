# 卫戍协议·规程 v1.3.0：策略具体数值

在「策略报告」中打开「具体数值」，可以查看 28 项策略补充的倍率、层数公式、升级节点、召唤物属性和指令使用次数。每项详情附资料来源。

- 望的「黑白相易」分别列出炎佑的基础面板、6 炎时的属性继承和 9 炎时的召唤与强化。
- 桑葚的「药枚实验」注明第 7 回合的护盾概率从 20% 升至 35%。妮芙的「溃心领域」列出每一档的使用次数。
- 顶部「任意词」支持搜索具体数值。只命中详情时会自动展开，例如输入 `35%` 可定位并展开「药枚实验」。
