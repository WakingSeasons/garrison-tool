# 卫戍协议·规程 v1.2.0：Boss 波次属性与巡逻路线

打开「敌方资料」，就能对照终极模拟领袖的开场属性、共享血量、随行敌人和巡逻路线。

- **Boss 波次属性**：在领袖卡片点「查看相关波次属性」。提供终极模拟单人开场面板、2～4 人的共享血量参考，以及普通领袖战和适用的隐秘核心。共覆盖 10 名领袖、16 个阶段。
- **随行敌人**：直接查看固定随行敌人和领袖部件的生命、攻防、法抗、基础攻击间隔和移速。单人场、双人场数量并排显示。实际怪种和数量取决于本轮怪组的随机替换位单独标出。
- **巡逻路线**：铳、鳍、矩兽的「查看路线」显示一张同盟完整场地图，可切换战场并点图放大。
- **特训敌人属性**：点「查看属性」查基础数值，头像和名称仍可打开 PRTS 详情。

波次参照本季关卡配置及[路标档案馆出怪预览](https://www.lubiao.wiki/tools/garrison-spawn-preview)。终极模拟面板、多人共享血量和点间寻路为参考，页面已标注社区推算和实战核实情况。
