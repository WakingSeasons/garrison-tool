# 截图识别标记对象 · 2026-11-16

用户在当前阵容管理中放入七名默认标记干员。通过现有用户浏览器的页面读取到：砾、云迹、承曦格雷伊、罗比菈塔、青枳、霍尔海雅、空弦；不修改该阵容。

截图识别页添加标记编辑器：输入干员或盟约名，显示至多8条候选，点击/上下键+Enter添加，已选项去重；每个标记可删除。名单存入既有工作区markedItems，旧存档初始化上述七名，用户主动删空后保留空名单。名单与阵容独立。

标记增删立即更新当前结果，不重新识图、不自动套用BAN；复制文字包含标记结论。本次不更改现有游戏BAN判定规则。
